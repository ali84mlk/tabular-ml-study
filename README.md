# Tabular Machine Learning Study

An experimental machine learning project focused on understanding and comparing classical
tabular classification methods on a real-world dataset.

## Project Status

🚧 Early development

## Objective

The goal of this project is to build a complete tabular machine learning workflow,
from exploratory data analysis and preprocessing to model comparison, validation,
and error analysis.

## Planned Experiments

- Exploratory Data Analysis
- Data preprocessing
- Baseline model
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- LightGBM
- Cross-validation
- Hyperparameter tuning
- Feature importance
- Error analysis
